騎手の調子 — いい馬を馬券内に入れられたか

いい馬 = (A. 指標がレース内3位以内 かつ 1番手との差 1.5秒以内 / B. 勝つルートの当てはまった数 21以上) かつ 体重の危ない材料なし (牝馬 6〜8kg 増減 / 4歳以上 +10kg以上)。2020年〜2026/11/15。
期待 = いい馬の種類ごとの全騎手の3着内率 (Aだけ 35.7% / AとB 54.4% / Bだけ 34.9%)。差 = 実際の馬券内 − 期待 (マイナス = 入れられなかった = 不調)。 通算比 = 直近30日の3着内率 − 通算の3着内率 (その騎手自身の普段と比べた調子)。
判定 = 地力スコア (通算の「実際の馬券内 − 期待」÷ (騎乗数 + 100) = 1騎乗あたり期待より何ポイント多く馬券内に入れるか): ◎ 信頼 +5pt以上 / ○ 上位 +2〜+5pt / 普通 -2〜+2pt / × 割引 -2pt未満 (あまり買わない)。
検証 (2024年〜、その日より前のデータで計算 → 先30日): ◎ +7〜+20pt / ○ +4.6pt / 普通 +0.7pt / × −3〜−4pt と、先の成績もこの順に並んだ。 直近の調子は先の成績をほとんど当てられなかったので 参考表示 のみ (▼ 調子が悪い = 直近30日 40%以上 かつ 直近14日 20%未満)。
